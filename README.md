# Kas Christo

Halaman untuk memilah transaksi rekening **BRI** (Bonsari · Kebun Wakaf · Rumah NGT) dan **BCA** (pribadi Christo), lengkap dengan catatan "untuk apa" di setiap transaksi.

Repo ini **hanya berisi halaman** (`index.html`) dan kode backend (`Code.gs`, tanpa kunci). **Tidak ada data rekening di sini.**
Data tersimpan di Google Sheet pribadi milik pemilik, lewat Google Apps Script, dan hanya bisa dibuka lewat link khusus dari pemilik.
